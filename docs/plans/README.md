# Historical plans

Files in this directory are implementation plans and design records from earlier development phases. They may contain superseded paths, commands, UI behavior, schemas, or architectural assumptions.

Do not use a phase plan as the source of truth for current behavior. Start with [`../README.md`](../README.md), the repository [`AGENTS.md`](../../AGENTS.md), and the current documents under [`../codebase/`](../codebase/) and [`../contracts/`](../contracts/).

Keep plans for decision history. Update current documentation instead of rewriting an old phase plan after implementation has moved on.
